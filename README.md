# niigata-ax-project

自治体や地域の事業者が AI で業務を変えるための、勉強会の資料と事例を集めるリポジトリです。新潟から始めて、全国に広げます。

## 要約

地域で AI を使った業務改革（AX）が進みにくい最大の理由は、事例と具体的なやり方の情報が足りないことです。このリポジトリは、その情報の入口になることを目的にしています。

- 勉強会で使った資料を、そのまま読める形で置いています。
- 市町村や事業者の取り組みを、1 件ずつ事例として置いています。
- 業務にそのまま使えるアプリを紹介しています。いまは経理アプリ [keiri-app](https://github.com/strickland-inc/keiri-app) があります。
- 誰でも読めて、自由に使えます。事例の追加や訂正も受け付けています。

チームみらいが公開しているリポジトリの作り方を参考にしています。

## 何が置いてあるか

| 場所 | 中身 |
|---|---|
| [studies/](studies/) | 勉強会の資料。1 回につき 1 フォルダです |
| [cases/](cases/) | 市町村などの事例。1 件につき 1 ファイルです |
| [apps/](apps/) | 業務で使えるアプリの一覧。アプリ本体は別のリポジトリにあります |

## 読み方

1. 勉強会の資料を読みたいときは、[studies/](studies/) を開きます。
2. 自分の自治体に近い事例を探すときは、[cases/](cases/) を開きます。地域ごとにフォルダが分かれています。
3. 業務で使えるアプリを探すときは、[apps/](apps/) を開きます。経理アプリの導入のしかたも、そこにあります。
4. 探している事例がなければ、Issue で「こんな事例を知りたい」と書いてください。

## 参加の仕方

- **Issue** は、知りたいこと、困っていること、事例の誤りの指摘に使います。
- **Pull Request** は、事例の追加と訂正、資料の修正に使います。

書き方と、載せてはいけない情報は [CONTRIBUTING.md](CONTRIBUTING.md) にあります。GitHub に不慣れな方は、Issue に文章を書くだけでも参加できます。

## ライセンス

このリポジトリの文章、資料、事例は [CC BY 4.0](LICENSE) で公開しています。出典（niigata-ax-project）を示せば、コピー、改変、商用利用ができます。

第三者が作った画像や素材は対象外です。出所と条件は [CREDITS.md](CREDITS.md) にまとめています。

[apps/](apps/) に載せたアプリは別のリポジトリにあり、ライセンスもそちらに書いてあります。

## 注意

- このリポジトリは、特定の自治体や行政機関の公式な見解ではありません。
- 事例の効果や費用は、掲載時点で書き手が示した内容です。導入するときは、自分の組織の条件で確かめてください。
