# 事例

市町村や地域の事業者が、AI を使って業務をどう変えたかを 1 件ずつ置きます。

## 置き方

```
cases/
├─ _template.md          書式の見本
└─ niigata/              地域ごとのフォルダ
   └─ nagaoka/           自治体ごとのフォルダ
      └─ 事例名.md
```

- 地域と自治体のフォルダ名はローマ字です。
- ファイル名は日本語で、取り組みが分かる名前にします。
- 書き方は [_template.md](_template.md) をコピーして使います。

## 先頭の項目

| 項目 | 意味 |
|---|---|
| title | 事例の題名 |
| prefecture | 都道府県名 |
| municipality | 自治体名、または事業者名 |
| field | 業務の分野。例として、窓口、文書作成、問い合わせ対応、経理 |
| tools | 使った製品やサービス |
| period | 取り組んだ期間 |
| cost | かかった費用と、その内訳 |
| effect | 効果。数字には測った方法を添える |
| source | 出典。自治体の公表資料、報道、本人への確認のどれか |
| published | このファイルを置いた日 |
| consent | 公開について、関係者の同意を確認したか。確認した、または公表資料のみ |
